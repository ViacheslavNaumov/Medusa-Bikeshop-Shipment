# Medusa Bikeshop Shipment

A modern e-commerce solution for bikeshops with advanced shipment tracking capabilities.

## Features

- Create and manage shipments
- Track shipment status
- Multiple payment methods with Stripe integration
- User management
- Responsive storefront built with Next.js

## Tech Stack

- Medusa.js v2 (Backend)
- Next.js (Frontend)
- PostgreSQL (Database)
- Stripe (Payment Processing)
